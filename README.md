# Manual de radioaficionado

Manual libre en español para preparar la autorización de radioaficionado en España.

Se publica en <https://mshodai.github.io/manual-radioaficionado/> con [Zensical](https://zensical.org).

## Compilar en local

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/zensical serve
```
